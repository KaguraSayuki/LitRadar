# 合成测试数据

本目录的邮件从零构造，用于测试编码、断行、关键词高亮、作者拆分、链接解析和入库。
它不代表任何人的订阅、阅读记录或研究偏好。

`xmol_sample.eml` 使用 `example.com` 邮箱、`10.5555/litradar.example.` 开头的虚构
文献标识、虚构作者和论文标题。外部站点链接只演示解析结构，测试不会访问这些链接。
样本不包含真实退订链接、订阅追踪像素或个人标识。

新增样本时继续使用完全合成的数据；不要从真实邮件删除邮箱地址后直接提交正文。
对应的隐私约束和解析回归见 [邮件测试](../tests/test_xmol_parser.py)。
