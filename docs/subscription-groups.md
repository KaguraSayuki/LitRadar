# 研究方向与评分

一个研究方向是一套独立的检索和评分偏好。同一篇文献可出现在多个方向中，
并得到不同的相关度评分。

## 添加和管理方向

在“设置 → 研究方向”选择“新增研究方向”，填写名称、说明、关注内容和检索条件。
每个输入框每行一项。预览满意后保存，再点击“更新这个方向”获取文献。

检索条件决定去哪里发现文献，评分偏好决定已收集文献的优先级。排除内容会筛选标题、
摘要等文本；如果只想排除某类标题，请使用标题筛选。种子论文用于发现后续引用它们的工作。

可以复制、改名、停用或调整方向顺序。改名和停用不会删除历史文献。新方向从之后的
检索或邮件采集中获得文献，不会自动继承整个历史文献库。

## 评分如何更新

| 操作或变化 | AI 会评估哪些文献 |
| --- | --- |
| 普通“排序”或“全部运行” | 本方向从未成功获得 AI 评分的文献，以及未完成的重评任务 |
| 关键词或评分偏好改变后的首次运行 | 所有待初评文献，加上按旧分数或旧排名选定的历史文献 |
| “全部重排” | 当前方向已入库且通过排除规则的全部文献 |

这里的“新”指本方向尚未成功评分，与发表日期、已读状态无关。较早发表的新入库文献
也会评分。首次导入大量文献时，每篇合格文献都需要一次模型评估；日常更新则复用已有结果。

### 选择历史重评范围

在方向编辑页的“评分更新”选择一种方式：

- **按原综合分筛选**：重评达到指定分数的文献，默认至少 70 分。
- **按原排名筛选**：重评排名前 N 的文献，默认 100 篇；并列时最多取 N 篇。

使用阅读列表中的综合分，只从本方向已有 AI 评分的文献中选择。这些限制只用于历史
重评，不限制新文献首次评分。范围在下一次排序开始时确定，之后不会随着分数变化继续扩大。

改变方向说明、关键词、关注期刊、作者或排除偏好，会在下一次运行应用这个范围。
只改名称、列表顺序、重复项、空白、模型、排序权重或新增收藏反馈，不会自动重评历史文献。
保存设置本身不调用 AI；连续修改后，以运行时保存的偏好为准。

未进入重评范围的文献保留旧 AI 分数和理由。若研究方向有较大变化，旧低分文献可能
重新变得相关，此时可使用全部重排。

### 全部重排与失败续跑

打开“统计 → 重新评估历史文献”，核对显示的当前方向和文献数量，再点击“全部重排”。
它会刷新这个方向的所有合格文献，包括摘要时间范围之外的旧文献；仍执行当前排除条件。

全部重排只更新评分，不重新收邮件、检索或生成摘要。“全部运行”仍使用日常增量评分。
全局 AI 或方向精排关闭时不会进行 AI 评分，待完成工作会在重新启用后继续。

结果逐批保存。失败时保留旧分数，未取得首次评分的文章继续等待。再次点击普通“排序”
会续跑未完成部分，成功批次不重复请求。再次点击“全部重排”则会重新刷新整个范围。

## 如何理解结果

综合分结合 AI 判断、关键词相关度和规则加分。每次排序会更新本地关键词与规则分，
所以复用 AI 结果时综合分仍可能小幅改变。

- **关键词分 / 待 AI 评分**：还没有成功的 AI 判断，不代表文献不相关。
- **历史评分**：沿用以前的结果，尚未按当前偏好重新评估。
- **待重评**：这次重评未完成，当前继续显示旧结果。

文献详情可查看各部分得分、AI 评分时间及是否使用当前偏好。升级前的旧评分会保留，
因无法确认其偏好版本而标为历史评分；升级不会因此自动重排整库。

## 多方向之间共享什么

| 内容 | 范围 |
| --- | --- |
| 文献题录、原文摘要、引用数与期刊信息 | 共享 |
| 收藏、已读状态 | 共享 |
| 评分、推荐理由、不感兴趣与规则排除 | 每个方向独立 |
| 中文标题与中性摘要 | 共享 |
| 摘要中的“对研究的用处” | 每个方向独立 |

邮件中的文献会加入采集时启用的方向，再按各自偏好筛选。每个方向的检索结果只加入
该方向。切换其他标签页的方向，不会改变当前页面上反馈和运行操作的目标。

新 AI 评分会参考收藏与不感兴趣的示例；这些反馈本身不会触发全库重评。
摘要有自己的更新规则，补齐或更新原文摘要、改变方向说明后，后续摘要运行可能产生额外调用。
