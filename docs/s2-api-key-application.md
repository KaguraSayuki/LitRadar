# Semantic Scholar 接入参考

在服务方申请个人 API 密钥后，将其填入“设置 → 数据与邮箱 → Semantic Scholar”，
保存并测试连接。LitRadar 的检索和被引追踪需要该密钥。

申请用途可以说明：使用自托管工具发现论文、追踪被引记录，并补全文献标题、摘要、
作者、期刊及开放获取链接。数据用于个人文献阅读；若启用 AI，相关文本会发送到
自行配置的模型服务作评分和摘要，不用于本项目的模型训练。

请按自己的实际用途填写申请，不需要公开具体研究方向、检索式或种子论文列表。
每日请求估算应计入各方向的检索页数、被引追踪页数、批量补全和重试；首次导入可能更多。
服务的额度和要求以获批账号及官方说明为准，项目不预设你的请求额度。

接入后的操作见[使用指南](web-settings.md#连接数据源与邮箱)。
