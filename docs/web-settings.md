# 使用指南

安装步骤见 [README](../README.md#快速开始)。本页介绍网页中的日常操作；
多方向和评分规则见[研究方向与评分](subscription-groups.md)。

## 完成首次设置

通过一次性设置链接建立访问密码，然后依次完成服务连接和研究方向设置。
没有准备使用的服务可以保持关闭；没有模型密钥时仍可收集和阅读文献，使用关键词与规则排序。

在“研究方向”新增一个方向，填写关注内容、排除条件和检索条件。每行一个术语或短语，
不用写查询代码。先预览检索结果，再保存。预览访问文献来源，但不调用 AI，也不将结果入库。

保存只更新设置。需要处理文献时，点击“更新这个方向”或统计页的“全部运行”。
正在运行的任务继续使用启动时的设置，新任务读取保存后的设置。

## 连接数据源与邮箱

“数据与邮箱”中按需接入服务：

| 来源 | 主要用途 |
| --- | --- |
| X-MOL 订阅邮件 | 导入邮箱中收到的订阅推荐，或上传导出的邮件文件 |
| Semantic Scholar | 检索文献、追踪种子论文被引记录、补全摘要等信息 |
| Crossref | 补全文献信息，也可开启关键词检索 |
| OpenAlex | 可选的关键词检索来源 |
| easyScholar | 显示期刊等级和影响因子 |

使用 Semantic Scholar 检索或被引追踪前需填写密钥；OpenAlex 检索和 easyScholar 展示也需要
对应密钥。连接成功不代表一定能检索到结果，可结合方向页的预览调整条件。

邮箱有两种常用接入方式：

- **连接邮箱**：填写服务器、账号和密码或授权码，测试已保存的连接。测试不会标记已读或移动邮件。
- **上传邮件文件**：选择 `.eml` 文件，每次最多 20 封、每封不超过 5 MB。上传后在下一次更新时解析。

IMAP 暂不支持 OAuth2。如果邮箱只允许 OAuth2，可使用文件上传，或将订阅转发至支持授权码登录的邮箱。
开启“处理成功后标为已读”时采集未读邮件；关闭后按邮件标识去重。应用只解析订阅邮件，不抓取 X-MOL 网站。

密钥留空表示保持原值；需要移除时使用“清除”。网页不显示原始密钥。
标为“部署管理”的凭据需要维护者修改，不能在网页覆盖。

## 接入 AI 与选择模型

在“默认模型连接”填写服务方提供的 API 根地址，保留要求的路径，例如 `/v1`。
密钥会发送到这个地址，应使用你信任的服务。

1. 保存密钥。
2. 点击“获取模型”，从返回列表中选择文本模型；服务不提供列表时可以手动填写模型名。
3. 保存连接设置，再点击“测试兼容性”。测试会进行少量模型调用。

获取模型列表不会生成内容，选择模型后仍需保存。高级兼容选项通常保持“自动”即可；
遇到不兼容的服务再由维护者协助调整。当前支持 OpenAI Chat Completions 兼容接口，
不直接支持其他原生协议。一个默认连接供评分、摘要和关键词建议使用。

“AI 与阅读”可以关闭全局 AI、调整深度摘要数量和摘要时间范围。每个方向还可单独关闭
AI 精排；这一开关只影响评分，摘要仍由全局 AI 开关控制。

## 更新文献与查看进度

方向卡片的“更新这个方向”和统计页的“全部运行”会依次采集、补全、评分和生成摘要。
也可以只运行某个阶段。邮件和元数据补全处理共享文献库；检索、评分和摘要按所选方向处理。

进度面板显示阶段、数量和耗时。评分结果区分首次评分、历史重评、复用评分和待完成数量。
任务在服务器后台执行，刷新或离开页面不会重复启动，也不会中止任务。

部分失败时已完成的结果保留。评分中断后，再点“排序”会处理尚未完成的文献。
不要用“全部重排”代替普通重试：它会重新评估整个方向。两者的区别见
[评分更新规则](subscription-groups.md#评分如何更新)。

## 设置每天更新

维护者完成调度接管后，在“自动更新”选择时间、时区和参与方向，保存并启用计划。
页面会显示调度状态和下次运行时间。

每天最多自动执行一次。重启后可以补跑当天错过的更新，不补跑更早日期；失败或中断的
当天任务需要手动重试。流水线忙时会稍后运行。若页面提示尚未接管或调度进程无响应，
请维护者按[部署指南](deployment.md#自动更新)检查。

## 密码与操作授权

阅读登录有效期为 12 小时。进入设置或执行受保护操作时，需要网页内的 **5 分钟授权**。
授权期间可连续保存和切换设置页，操作不会延长有效期。

授权只在当前浏览器有效，同一浏览器的标签页共用；不同设备、浏览器和无痕窗口分别验证。
“退出授权”会锁定当前浏览器的操作，保留阅读登录。到期后可以重新输入密码或前往其他页面，
未保存的表单内容会保留。已启动的任务继续运行。

## 常见问题

| 情况 | 可以怎么做 |
| --- | --- |
| 预览没有结果 | 检查来源是否开启、连接是否可用，减少必须同时包含的条件 |
| 只有关键词分 | 检查全局 AI、方向的 AI 精排开关及模型连接；重新运行排序 |
| 显示历史评分 | 该分数保留自以前的偏好；按需要调整重评范围或全部重排 |
| 显示待重评 | 旧分数仍可查看；下次普通排序继续未完成部分 |
| 保存提示版本冲突 | 在新标签页打开最新设置，对照后重新编辑，避免覆盖另一处修改 |
| 达到运行次数限制 | 等待下一次可运行时间，或在高级阅读设置调整次数和间隔 |
| 忘记访问密码 | 请维护者在实例本机重设密码，无需删除文献库 |

“访问与维护”可更换密码、退出登录、导出普通设置和恢复最近五份备份。
普通导出不包含密钥，但可能包含研究偏好，应私下保存。恢复设置不会恢复文献数据库；
恢复运行设置后自动更新会暂停，需要检查并重新开启。
