# 网页设置指南

实例安装启动后，日常配置均可在导航的“设置”中完成。安装、证书、监听地址和数据库
迁移交给维护代理处理；网页保存普通偏好不会更改这些部署参数。

## 首次使用

1. 打开安装代理提供的一次性设置链接，设置至少 8 位的访问密码。链接 30 分钟有效，
   使用后失效。普通访客不能自行签发链接或抢先设置密码。
2. 在“数据与邮箱”接入需要的服务。API 密钥或邮箱授权码分别保存；保存账号、服务器
   等连接参数后，再点击“测试已保存的连接”。没有模型密钥也能继续配置。
3. 在“研究方向”新增方向，填写名称、说明、关键词、期刊与检索条件。
4. 点击“预览检索结果”，检查条件是否过宽或过窄，然后保存方向。
5. 部署代理完成调度接管后，在“自动更新”选择时间、时区和方向并开启计划。

每一步均可保存后继续。服务接入不是必填检查表：不使用某项功能就可以关闭对应来源。
例如没有 Semantic Scholar 密钥时，可启用 Crossref 检索，并在条件中选择
“Crossref / OpenAlex”。未接入 AI 时，排序使用关键词与规则，已有摘要仍可阅读。

登录会话有效期为 12 小时。更换密码会使其他已有会话失效；忘记密码时，请维护代理
在实例本机执行 `litradar admin-password` 恢复访问，不需要重建数据库。

## 研究方向与文献筛选

“新增研究方向”始终可见，包括空库和单方向实例。改名保持方向身份，复制产生新的
方向；停用、恢复和上下移动不会删除历史文献。新建方向不会自动获得全部历史成员。

每个词语输入框每行填写一项。核心词代表研究主题，加分词和近期主题调整推荐优先级；
排除内容检查标题、摘要等文献文本，标题排除和标题开头筛选可减少误伤。
种子文献接受 DOI 或含 DOI 的论文链接，用于追踪后续引用。ISSN 是可选辅助信息。

检索条件按行添加、移除，各条结果取并集：

| 输入 | Semantic Scholar | Crossref / OpenAlex |
|---|---|---|
| 必须全部包含 | 组合为与条件，短语自动引用 | 合成一组检索词，由来源自己的搜索规则匹配 |
| 其中任意一个即可 | 组合为或条件 | 每个备选词与共同检索词组合，分别查询后合并 |
| 排除这些内容 | 组合为排除条件 | 不保证查询级排除，请填入上方文献筛选 |

Crossref 的结果可能只匹配部分术语，需结合预览和后续筛选判断。指定期刊的
Semantic Scholar 条件使用“数据与邮箱 → 高级设置”中的限定期刊列表。

旧配置能完整识别的简单查询会显示为表单。无法完整转换的复杂查询继续原样使用，
修改名称或偏好不会改变它们。若要重建，先添加新条件、预览，再勾选移除对应旧条件。
新表单保存的通用查询带有编辑信息，重新打开时仍可编辑。

预览最多执行前 5 条条件、显示 20 篇论文，采用当前保存的来源和回溯范围；只使用
当前表单中的查询，不应用排序阶段的全部关键词、期刊或排除规则。预览会访问学术
服务，但不保存设置、不入库、不调用 AI。连接失败与连接成功但零结果分别提示。

“建议英文关键词”是可选模型调用，会把方向说明发给已接入的模型，可能产生少量费用。
结果先供检查，点击采用只填入表单，还需要保存；不会自动开始流水线。

## 数据、邮箱与凭据

API 密钥、邮箱授权码留空表示保留，清除必须点击单独按钮。网页只显示是否已设置和
管理方式，不显示原始值。各服务凭据分开保存，其他普通连接参数通过页底按钮保存。

| 凭据来源 | 生效规则 |
|---|---|
| 部署进程的环境变量 | 优先级最高，包括显式空值；网页显示部署管理，需代理修改并重启 |
| 应用管理的私有凭据文件 | 可在网页更换，下次调用生效；清除也会屏蔽旧 `.env` 值 |
| 配置文件旁的 `.env` | 兼容旧部署，优先级最低；无需将值导入进程环境 |

已开始的流水线使用固定凭据快照，途中更换密钥不会让同一任务混用两把密钥。
凭据文件仅保存密码哈希，不保存访问密码明文；普通设置备份和导出不含这份私有文件。

邮箱支持上传 `.eml`、用户名加授权码的 IMAP，以及由部署管理的 Maildir。IMAP 暂无
OAuth2。用普通发件邮箱或域名筛选邮件即可，无需填写搜索表达式；无法转换的旧条件
默认保留，只有明确选择替换才改变。

“处理成功后标为已读”开启时只采集未读邮件；关闭时只读访问并按邮件标识去重。
连接测试只登录、只读选中文件夹并统计匹配邮件，不读取邮件正文、不标记已读、
不移动或删除邮件。模型连接测试会发送一条简短测试消息，可能产生少量费用。

上传邮件每次 1–20 封，每封最多 5 MB。文件进入应用收件目录，下次更新时解析；
应先启用邮件采集并选择上传模式。自定义服务器收件和归档路径由部署代理管理。

## AI、阅读与运行限制

常用设置包括全局 AI 开关、每个方向的精排和深度摘要范围、文献处理天数、期刊标签
与每次新期刊查询上限。高级设置提供模型地址与名称、超时、批次、生成随机程度、
排序权重及运行频率。三类权重须为非负有限值，且总和大于零。

每组 AI 精排开关只控制排序。若全局 AI 仍开启，摘要阶段仍可能产生费用。同篇论文
的中性摘要在方向间复用，方向性说明分别生成。保存新偏好不会立即清除或重算旧评分。

期刊展示项可勾选，名称可缩写，刊名别名可成对填写。常见分区缩写有普通文本表单及
样例预览；无法转换的旧正则规则继续保留，不需要用户重写。

受限阶段、最短间隔和每日次数适用于网页、CLI 和应用调度，统一在流水线锁内检查。
次数按所选时区的自然日计算；分组阶段按方向计数，邮件和补全的全局记录计入相关检查。
完整更新也检查其中受限的子阶段。设为 0 可关闭对应次数或间隔限制。
这些设置限制运行频率，不是货币预算；连接测试、预览与关键词建议也不按流水线次数计费。

## 自动更新

维护代理须先停用原 systemd、launchd 或 Windows 每日任务，并记录接管确认。
网页不能代替这个宿主机步骤。完成后，用户只需选择每天时间、时区和更新所有启用的
方向，或指定一部分方向。邮件与元数据补全仍是全局阶段。

调度进程通常每 30 秒重读计划。网页显示进程响应、上次状态、下次时间和可解释的错误：

- 每个本地日期最多自动执行一次；当天改时间也不会重复运行。
- 重启后补跑当天已到时间但尚未执行的更新，不补跑更早日期。
- 流水线忙时不占用当天任务名额，稍后重试。
- 夏令时缺失的时间顺延；重复时间取第一次。
- 失败或中断的当天任务不自动重试。检查统计记录后，可单独手动更新。

运行设置恢复后，自动更新会暂停，需要检查并重新开启。恢复研究方向不会恢复文献库，
若原计划指向已不存在的方向，请重新选择。监听、重启和外部定时任务不由普通保存操作修改。

## 保存冲突、备份与维护

保存更新当前页字段，保留其他页、其他方向及未编辑的扩展内容。设置和研究方向分别
保留最近五份备份，写入使用文件锁、唯一临时文件和原子替换。它们与凭据属于独立文件，
首次设置是分步保存，不是跨文件事务。

另一标签页或本机程序改动后，旧表单会拒绝保存并保留输入。可以在新标签页打开最新
设置进行对照，然后重新编辑；不会自动覆盖较新的内容。

“访问与维护”支持更换密码、管理可选接口口令、导出普通设置、查看和恢复备份。
恢复运行设置保留当前访问配置、数据库位置和监听参数，并暂停自动更新。
私有凭据应由维护代理单独备份，POSIX 文件权限为 600；Windows 应限制目录 ACL。
磁盘满或文件权限问题需要代理处理，已保存的原文件会保留。

实例信息显示当前请求使用的访问地址和实际数据文件位置。安装升级及配置文件损坏的
本机恢复方法见 [部署与维护](deployment.md)。
